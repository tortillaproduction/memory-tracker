# ゲート（Androidアプリ）のセットアップ

SNSや動画アプリを開いた瞬間に、しばらく訪れていないサイトを全画面で提示する「ゲート」の使い方です。
Androidのみ対応です（iPhoneでは使えません）。

## 用意するもの

- Androidスマホ（Android 8.0以上）
- 配布されたAPKファイル（`app-debug.apk`）
- Memory TrackerのWeb版にログインできるPC、またはスマホのブラウザ

## 1. Webでゲートに切り替える

1. Web版にログインし、右上のアイコン → **Notifications** のトグルを **Gate** 側にする
2. 「Gate setup」画面が開くので **Show QR code** を押す（QRコードは一度しか表示されません。スマホで読み取るまで閉じないでください）

ゲートに切り替えても、スマホとの接続が3日以上途切れている間はメールも届きます。

## 2. アプリをインストールする

1. APKファイルをスマホに送り、ファイルを開いてインストールする
2. 「提供元不明のアプリ」の許可を求められたら、そのアプリ（ファイルマネージャーやブラウザ）に許可する

## 3. アプリのチェックリストに沿って設定する

アプリ「Memory Tracker Gate」を開くと、5つのチェックリストが表示されます。上から順に進めてください。端末の再起動は原則不要です。

| ステップ | やること |
|---|---|
| 1. Connect | **Scan QR code** でWebのQRコードを読み取る。読み取れない場合は、Webの **Copy setup code** でコピーした文字列を **Can't scan? Paste the setup code** に貼り付ける |
| 2. Turn on the service | **Open accessibility settings** から「Memory Tracker Gate」をオンにする |
| 3. Allow background | **Allow** を押し、ダイアログで許可する。機種ごとの案内（下記）も設定する |
| 4. Choose apps | ゲートを出したいアプリにチェックを付けて **Save**（最初はすべてオン） |
| 5. Try it | 一覧のアプリを開き、ゲートが出るか確かめる |

### スイッチがグレーで押せない（ステップ2）

Android 13以降では、APKから入れたアプリのユーザー補助が「制限付き設定」でロックされます。

1. アプリ内の **Open app info** を押す（または 設定 → アプリ → Memory Tracker Gate）
2. 右上の **⋮** → **制限付き設定を許可** を押す
3. もう一度ステップ2のスイッチをオンにする

### 機種ごとの設定（ステップ3）

省電力機能がゲートを止めてしまうことがあります。メニュー名はOSのバージョンによって異なります。

- **OPPO（ColorOS）**
  - アプリ情報 → バッテリー使用量 → **バックグラウンドでの実行を許可**：オン
  - アプリ情報 → **自動起動を許可**：オン
  - 最近使ったアプリの一覧で、このアプリのカードを下に引く（または ⋮ → ロック）
- **Motorola**
  - アプリ情報 → アプリのバッテリー使用量 → **制限なし**

### ステップ5でゲートが出ないとき

- 期限切れのサイトがない、または今日すでにチェックイン済みだと出ません（画面上部に理由が表示されます）
- 同じアプリで試し直すときは5分空けてください
- それでも出ない場合は、**端末を再起動してから、もう一度お試しください**（OPPOなど一部の機種では、省電力設定の反映に再起動が必要なことがあります）

## ゲートの使い方

- 対象アプリを開くと、期限切れのサイトが最大3件表示されます。**Open** を押すとサイトが開き、訪問が記録されます
- 1件開くと、その日はもうゲートは出ません
- どうしても開きたくないときは、画面下の **Hold 3s to skip today** を3秒長押しすると、その日だけ解除されます
- ゲートは2分たつと自動で閉じます

## ゲートを止めたいとき

アプリが反応しない場合も含め、いつでもOSの設定から止められます。

- 設定 → ユーザー補助（OPPOは「その他の設定」の中にある場合があります）→ **Memory Tracker Gate** → オフ

アプリの設定画面の **Open accessibility settings** からも同じ画面を開けます。完全にやめる場合は、アプリをアンインストールし、Webの通知設定を **Email** に戻してください。
